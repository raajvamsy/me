## RGB curriculum

Checkpoints teach pixel fill, leaf patches, segments, per-portrait layouts and shared layouts. Reference photos are used only in teaching, and generation samples a layout and then fills each region. Sunsets look good at 64×64, while flowers still look bad.

## Inside the model

The design rule was that it can't be a wrapper. If `pipe(prompt)` still works with the field detached, it doesn't count. So each cross-attention block in SDXL-Lightning takes its keys and values from the live field, with convolution, self-attention and the VAE frozen. Each denoising step both reads from the field and writes to it.

`funnel-english-curriculum` points at the same work, with no difference between the two branches at their tips.

## Results

| Test | Result |
|---|---|
| Signatures | About 4% change |
| Hills and ocean, taught then combined | With the field off, images matched the untaught baseline. With it on, a path appeared in the scene |
| Field growth in that run | 0 to 16 funnels and 2 meta-funnels across 8 teach passes |

The honest caveat is that SDXL can already combine hills and ocean from the prompt alone. The field's measurable contribution was a detail, not the concept.

## Why the effect is small

A later audit of `funnel_unet.py` found the projections from the field into the model start random and are never trained. The field chooses which keys go in, but they arrive through fixed random transformations, so they can't carry a specific identity.
