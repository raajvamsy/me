## The question

Can a system learn language from byte exposure alone, with no LLM decoder and no regex or logic as its core?

## What the code holds

`funnel/` holds the field and its organs (hippocampus, cerebellum, sensory and more), and `curriculum/` holds the teaching packs. The master log records each phase.

## What I measured

| Test | Result |
|---|---|
| Empty brain | The same junk token for every probe |
| Teaching 7 real memories | It replayed what it had lived, but stitched the same pieces for different questions |
| More teaching | Quality fell, with code fragments and a single parenthesis as an answer |
| Nonsense input | It still spoke, with no gate to stop it |

## What it taught

Recall is real, but answering isn't. The brain had no verify step and joined stored fragments together, so more exposure gave it more to stitch and not more understanding.
