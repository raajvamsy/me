## The question

The main branch refuses to say anything it hasn't lived. What if that limit is removed?

## What changed

| | Main | This branch |
|---|---|---|
| Untaught cue | Silence or an echo | Often a new word order |
| Vocabulary | Lived sentences only | Lived words, in new sequences |
| Fluency | Collage | Markov-like English |

Invention is a bigram walk over words from lived memories, with no LLM decoder. The branch also fixed fission so that near-merged modes split properly, and added drive mechanisms.

## Result

Refuted as a route to language. Without a real generative model, invented text is word salad. Practice only strengthens whatever generator already exists, and it can't create one.
