## The question

Can the brain learn the reverse-diffusion step itself, without a frozen model?

## What the code holds

Input-conditioned residuals keyed on prompt, image signature and time step, `SceneProgram` priors, and a combination loop of RGB cuts and reverse steps until the result matches a target. About 3,400 lines were added, with tests for each piece.

## Result

Cut-based generation stays the primary generator, because polishing can't invent structure. It can clean up an image that already has a composition, but it can't supply one, which agrees with the wider conclusion of this line.

## The curriculum

Each stage repeated teaching until its error passed a gate. Harder stages add more noise, and the hardest needed 5 attempts.
