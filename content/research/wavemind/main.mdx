## What the code holds

| Part | What it does |
|---|---|
| Wave memory | Encodes tokens as waves and clusters them online |
| Background resonance | Keeps the field active between inputs, so it thinks on its own |
| Predictive processing | A transition model and prediction error |
| Tokenizer | Per-character handling for CJK, Thai and Hangul |

`backup/phase-5-complete` is a snapshot of this work, and `main-legacy` is an older line with nothing `main` lacks.

## Status

A research prototype validated on small corpora. It's a proof of concept of the architecture, not a product.
