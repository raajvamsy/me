## The problem

An early token-efficiency showcase compared memory against an unfairly weak alternative.

## What changed across the branches

| Branch | Change |
|---|---|
| `feat/fs-tools-honest-benchmark` | Removed the strawman, gave the baseline real filesystem tools and ran a real loop |
| `debug/memory-cost-postmortem` | A post-mortem. `code_search` now returns content inline by default |
| `fix/benchmark-polish` | Found a `.tsx` parser bug, moved to real token counts |
| `feat/graph-and-embed-cache` | Ran an N=3 stability benchmark for defensible final numbers |

## What it taught

Making the comparison fair found product bugs the flattering version had hidden. All of these were merged, and I'll publish the current numbers with the next version.
