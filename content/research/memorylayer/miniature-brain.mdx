## The change

22 memory tools were consolidated into 4: one each for writing, reading, code and maintenance. Each routes by intent or parameters. The branch also added `locate` and `impact` for code, and brought in WaveMind's ideas.

`feat/tool-redesign-v2` and the `tool-surface` design docs continued this, with fixes found by running scenarios.
